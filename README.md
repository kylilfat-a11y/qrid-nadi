# QRIS NADI

Aplikasi kecerdasan bisnis berbasis AI untuk UMKM: analisis transaksi QRIS, prediksi stok & penjualan, kesehatan finansial, rekomendasi bisnis, riwayat transaksi, serta laporan dan unduhan (Oktober 2026).

---

## Alur Layar Aplikasi

1. **Splash Screen**
2. **Onboarding**
3. **Login / Masuk Akun**
4. **Registrasi Akun UMKM**
5. **Dashboard Utama**
6. **Analisis Transaksi QRIS**
7. **Prediksi Penjualan & Stok**
8. **Kesehatan Finansial**
9. **AI Business Advisor**
10. **Riwayat Transaksi**
11. **Laporan & Unduhan**

---

## Menjalankan Proyek

```bash
# Install dependensi
npm install

# Jalankan server
npm run dev
```

Buka di browser: `http://localhost:3000`
