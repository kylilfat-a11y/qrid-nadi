# QRIS NADI - Solusi Cerdas Bisnis UMKM Berbasis AI

> **Data Hari Ini, Keputusan Lebih Baik untuk Masa Depan Usaha Anda**  
> *UMKM Maju, Ekonomi Kuat*

Platform kecerdasan bisnis berbasis AI yang mengolah data transaksi QRIS dan informasi operasional UMKM menjadi rekomendasi nyata untuk meningkatkan produktivitas, efisiensi modal, dan daya saing usaha.

---

## 📱 11 Layar Interaktif yang Tersedia

1. **Splash Screen** – Logo QRIS NADI, ilustrasi merchant UMKM, dan tagline resmi.
2. **Onboarding** – Panduan awal 3 pilar utama aplikasi dan navigasi geser.
3. **Login / Masuk Akun** – Autentikasi email, nomor HP, dan integrasi Google.
4. **Registrasi Akun UMKM** – Pendaftaran identitas toko, jenis usaha kuliner/retail, dan alamat.
5. **Dashboard Utama** – Ringkasan transaksi 30 hari (Rp 12.480.000), 4 aksi cepat (*Transaksi, Prediksi, Keuangan, Rekomendasi*), dan grafik tren harian.
6. **Analisis Transaksi QRIS** – Filter periode 7, 30, dan 90 hari, grafik batang dinamis Oktober 2026, dan daftar menu terlaris.
7. **Prediksi Penjualan & Stok** – Kurva proyeksi lonjakan penjualan akhir pekan (puncak Sabtu 17 Okt 2026) dan rekomendasi restock bahan baku.
8. **Kesehatan Finansial** – Laba bersih (Rp 4.680.000 / 37,5%), rasio omzet vs biaya, dan *donut chart* rincian biaya.
9. **AI Business Advisor** – Konsultasi AI cerdas interaktif untuk strategi promosi, efisiensi bahan baku, dan jam operasional.
10. **Riwayat Transaksi** – Daftar mutasi transaksi QRIS Oktober 2026 lengkap dengan pratinjau struk digital resmi.
11. **Laporan & Unduhan** – Laporan penjualan, stok, dan keuangan mingguan/bulanan yang siap diunduh dan dicetak dalam format PDF.

## 🚀 Menjalankan Proyek Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/<username>/<repo-name>.git
   cd <repo-name>
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan:**
   ```bash
   npm run dev
   ```

4. Buka di browser: `http://localhost:3000`
